# tskr

`tskr` is a lightweight Go CLI tool designed to manage branch-specific task context files (`task-requirements.md`, `task-implementation.md`, `task-tests.md`) across your Git repositories.

It maintains a centralized storage directory (`$HOME/.tskr`) for all your task files and creates symbolic links inside a `.task-refs/` directory in your project repositories.

## Overview

When working on complex features or bug fixes, keeping track of task requirements, implementation steps, and test plans inside your repository can pollute Git history across branches. `tskr` solves this by:

1. Storing task context files in `$HOME/.tskr/<repo-name>/<branch-name>/`.
2. Creating symlinks inside your local `.task-refs/` folder pointing to the active branch's context.
3. Automatically updating symlinks when you switch branches.

## Context Files & Configuration

By default, `tskr` manages three markdown files for every repository and branch:
- `task-requirements.md`: Task requirements and specifications.
- `task-implementation.md`: Implementation steps generated by AI agents or developers.
- `task-tests.md`: Test instructions and verification steps.

You can customize the list of task files and storage directory in your configuration file.

### Configuration Format

`tskr` supports **JSON**, **YAML**, and **TOML** formats stored at `$HOME/.config/tskr/` (`config.json`, `config.yaml`, or `config.toml`).

Example `config.json`:
```json
{
  "storage_dir": "/home/user/.tskr",
  "files": {
    "naming": [
      "task-requirements.md",
      "task-implementation.md",
      "task-tests.md"
    ]
  }
}
```

If `files.naming` is missing or empty, `tskr` falls back to the default task files list.

## Installation

### Option 1: Quick Install Script (Recommended)

Run the automated installer script (works on Linux and macOS, supporting both Intel and Apple Silicon):

```bash
# Automated release binary download & installation
curl -fsSL https://raw.githubusercontent.com/fibrasek/tskr/main/install.sh | bash

# Force build from source
curl -fsSL https://raw.githubusercontent.com/fibrasek/tskr/main/install.sh | bash -s -- --build-from-source

# Install to custom directory (e.g. /usr/local/bin)
curl -fsSL https://raw.githubusercontent.com/fibrasek/tskr/main/install.sh | bash -s -- --dir /usr/local/bin
```

### Option 2: `go install`

If you have Go installed:

```bash
go install github.com/fibrasek/tskr@latest
```

### Option 3: Build & Install via Makefile

```bash
# Clone the repository
git clone https://github.com/fibrasek/tskr.git
cd tskr

# Install to $HOME/.local/bin/tskr
make install

# Or install globally to /usr/local/bin (requires write permissions or sudo)
make install PREFIX=/usr/local
```

## Commands

### `tskr init`
Initializes user configuration at `$HOME/.config/tskr/config.json` and storage directory at `$HOME/.tskr/`.

```bash
tskr init
```

### `tskr config`
Inspects, sets, or converts configuration settings.

```bash
# Show active configuration and file path
tskr config show

# Set custom task file names (comma-separated)
tskr config set files.naming "requirements.md,tasks.md,notes.md"

# Change storage directory
tskr config set storage_dir "/custom/path/.tskr"

# Convert configuration format to YAML or TOML
tskr config convert yaml
tskr config convert toml
tskr config convert json
```

### `tskr start`
Runs inside a Git repository. Creates the task context files for the current branch and sets up symlinks in `.task-refs/`.

```bash
cd /path/to/my-repo
tskr start
```

### `tskr switch`
Updates symlinks in `.task-refs/` to point to the task context of the newly checked out Git branch.

```bash
git checkout feature/new-login
tskr switch
```

### `tskr sync`
Re-validates and recreates symlinks for the active repository branch.

```bash
tskr sync
```

### `tskr list`
Displays a formatted list of all tracked repositories and branches along with their assigned IDs.

```bash
tskr list
```

### `tskr completion <bash|zsh|fish>`
Generates autocompletion scripts for Bash, Zsh, or Fish shells.

```bash
# Bash (add to ~/.bashrc)
eval "$(tskr completion bash)"

# Zsh (add to ~/.zshrc or completions directory)
tskr completion zsh > ~/.zsh/completions/_tskr

# Fish (save to completions directory)
tskr completion fish > ~/.config/fish/completions/tskr.fish
```

### `tskr go <id>`
Outputs shell commands to navigate to a repository, checkout the branch, and switch symlinks.

```bash
tskr go 1
# Output: cd "/path/to/repo" && git checkout "main" && tskr switch
```

#### Shell Integration (Optional)
Add this function to your `.bashrc` or `.zshrc` to automatically execute navigation when using `tskr go`:

```bash
tskr() {
    if [ "$1" = "go" ]; then
        eval "$(command tskr "$@")"
    else
        command tskr "$@"
    fi
}
```
